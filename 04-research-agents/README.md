# 조사원·편집장 서브에이전트 — 보고서 기획 자동화

**AI 마에스트로 4회차 과제** — 문서 작성 에이전트 + 서브에이전트·Skill
부산대학교 총무과 · 2026. 9.

보고서를 써야 하는데 **무엇을 조사해 어떤 순서로 설득할지** 정하는 데 시간이 가장
많이 든다. 조사를 여러 사람에게 맡기고, 결과를 모아 목차와 스토리라인을 잡는 일을
**서브에이전트 다섯 + 편집장 하나**로 나눴다.

```
       ┌─ 정책조사원 × 3 (기관별)  ─┐
명령 ──┼─ 타대학조사원            ─┼─→ 편집장 ─→ 사용자와 대화 ─→ 목차·스토리라인 확정
       └─ 기관 내부 조사원        ─┘      (초안·쟁점)      (한 번에 하나씩)
```

**한 줄 명령으로 조사부터 목차 확정까지** 다시 돌아간다.

```bash
/manpower-research 국립대학 지원정책 확대에 따른 부족인력 재배치 방안
```

## 왜 이렇게 나눴나

### 조사원을 동시에 돌린다

다섯이 순서대로 돌면 한 시간이 넘는다. **한 메시지에 Agent 호출 다섯 개를 동시에**
보내면 15분에 끝난다. 각자 다른 기관을 맡으므로 서로 간섭하지 않는다.

담당을 기관 단위로 쪼갠 이유는 **한 조사원이 여러 기관을 맡으면 얕아지기 때문**이다.
정책조사원은 정의 하나를 세 인스턴스로 띄워 각각 한 기관만 파게 했다.

### 편집장은 혼자 확정하지 않는다

목차와 스토리라인은 **무엇을 싣고 무엇을 가릴지**의 문제라 기계가 정할 수 없다.
그래서 편집장의 역할을 「결정」이 아니라 **「선택지와 권고를 만드는 것」**으로 정의했다.

산출물에 반드시 **「확정이 필요한 쟁점」** 절이 들어간다. 쟁점마다
① 무엇을 정해야 하는지 ② 선택지 2~3개와 득실 ③ **권고안과 이유**를 적는다.
권고는 분명히 내되 결정은 사람이 한다.

실제로 이 방식으로 **쟁점 6건**을 하나씩 상의해 확정했다.

### 근거에 등급을 매긴다

편집장이 스스로 만들어 낸 장치다. 출처를 5등급으로 나눠 각 절에 표시한다.

| 등급 | 무엇 | 쓸 수 있는 정도 |
|---|---|---|
| **A** | 제도 원문 — 규정·지침·기본계획 본문 | 논지의 뼈대. 조문·쪽수까지 인용 |
| **A-** | 확정 전 원문(시안) | 「시안 기준」 명기 |
| **B** | 기관 확정 자료 | 핵심 숫자 |
| **B-** | 기관 검토 자료(안) | **「(안)」 명기.** 확정 사실처럼 쓰면 안 됨 |
| **C** | 언론 보도 | 보조로만. 논지의 축에 놓지 않는다 |

**`B-` 구분이 특히 중요했다.** 작년 내부 검토안을 확정 사실로 잘못 읽어
**이미 실행된 일을 「하겠습니다」로 건의할 뻔한** 사고가 실제로 있었다.

## 시행착오

### 1. 공공기관 게시판은 본문에 요약만 싣는다

정책조사원 **셋이 모두 같은 데서 막혔다.** 전담인력 요건·사업비 집행 기준 같은
**정작 필요한 조항이 전부 `.hwpx`/PDF 첨부 안에** 있었다. 웹 본문만 읽으면 핵심이 빈다.

3회차에서 만든 HWPX 파서를 재사용해 **첨부 추출 도구**를 만들었다
([`tools/fetch_attachment.py`](tools/fetch_attachment.py)).

```bash
python tools/fetch_attachment.py "<첨부 URL>" --out 첨부 --text
```

`<hp:t>` 의 `.text` 만 이으면 자식 요소 뒤의 `tail` 이 빠져 날짜·수치가 잘린다.
`tail` 까지 이어 붙여야 한다.

이 도구로 **교육부 기본계획·지자체 사업비 운영 매뉴얼·전문기관 사업 지침 원문**을
확보했고, 「언론 보도 기준」이던 근거가 **「제도 원문」으로 올라갔다.**

### 1-2. 마크다운으로 쓰고 한글로 낸다

보고서는 마크다운으로 쓰는 편이 빠르다. 표를 고치기 쉽고, 수치가 바뀌었을 때
전 문서를 훑어 대조하기도 쉽다. 그러나 **결재 문서는 한글이어야 한다.**

한글 COM 의 액션 API 로 문단·표를 하나씩 쌓는 방법도 있으나 표가 많은 보고서에서는
손이 너무 많이 간다. **한글이 HTML 을 그대로 읽는다**는 점을 쓰는 쪽이 안전하다 —
제목 단계·표·굵기가 그대로 넘어온다([`tools/md2hwp.py`](tools/md2hwp.py)).

```bash
python tools/md2hwp.py 보고서.md --pdf      # .hwp 와 함께 PDF 도 떠서 쪽수 확인
```

**두 가지에서 걸렸다.**

- **`nl2br` 확장을 켰더니 분량이 배로 늘었다.** 마크다운에 가독성을 위해 넣은 줄바꿈이
  전부 강제 개행이 되어, 3쪽짜리가 6쪽이 됐다. 문단 안의 줄바꿈은 공백으로 합쳐야 한다.
- **COM 이 남긴 한글이 다음 실행을 막았다.** 변환이 2분 넘게 멈췄다. 창 없는 한글
  프로세스가 남아 있었기 때문이다. 실행 전에 정리하되, **창이 있는(사용자가 열어 둔)
  한글은 절대 건드리지 않는다.**

```powershell
Get-Process Hwp | Where-Object { $_.MainWindowHandle -eq 0 } | Stop-Process -Force
```

### 2. 「실패하면 내려가라」가 시도조차 안 하는 핑계가 됐다

브라우저 기동 실패로 시간을 태우길래 「120초 넘으면 WebFetch 로 가라」고 적었다.
그랬더니 재실행에서 한 조사원이 **브라우저를 아예 켜지 않고** 조사했다.
규정집·정보공개 게시판을 하나도 못 열었고 수확이 절반이었다.

동시에, 다른 조사원 둘은 **실제로 시도했다가 기동에 실패**했다. 다섯이 Chrome 을
한꺼번에 띄우면서 경합이 났던 것이다. **문제가 둘이었다.**

그래서 규칙을 이렇게 바꿨다.

| 자료 | 무엇으로 |
|---|---|
| 정부·지자체 **보도자료·공고와 첨부** | WebFetch + 첨부 추출이 **오히려 낫다** |
| **규정집·정보공개·직제 개정안** | **브라우저가 아니면 못 연다** |

그리고 **시도와 실패를 기록에 남기게** 했다. 출처 표에 「수집 방법」 열을 두어
건마다 브라우저·WebFetch·첨부·검색 중 무엇으로 얻었는지 밝힌다.

### 3. 규정에 없는 것을 「없앴다」로 읽었다 ← 가장 위험했던 오류

내부 조사원에게 「작년 검토안이 어디까지 실행됐는지 현행 규정과 대조하라」고 시켰다.
조사원은 **14개 항목 중 8개를 「실행됨」으로 판정**했는데, 담당자 확인 결과
**7개가 틀렸다.**

원인은 단순했다. **현행 규정에 해당 직위가 안 보이니 「없앴다」고 읽은 것**이다.
그러나 **애초에 규정에 안 나오던 조직이면 없는 것이 당연하다.**

> **규정에 없다 ≠ 없앴다**

눈으로 확인하지 않았으면 **이미 한 일을 건의하는 보고서**가 나갈 뻔했다.
결재 자리에서 가장 나쁜 종류의 실수다.

**도구로는 못 막는 오류다.** 이 판정을 담은 산출물 머리에 「이 판정은 믿지 말 것,
정본은 별도 문서」라고 박아 두었다.

### 4. 인용한 수치를 스스로 검증하지 않았다

조사원 요약을 그대로 옮겨 쓰다가 **정원 관련 수치를 잘못 적었다.**
정원배정서에는 **기준정원과 한시정원이 따로 있는데 기준정원만 보고** 「직원 정원은
한 명도 안 늘었다」고 쓴 것이다. 실제로는 한시정원이 별도로 있었다.

담당자가 잡아 주지 않았으면 그대로 나갔다. 이후 **보고서의 핵심 수치는 전부
원자료(xlsx·hwpx)를 직접 열어 재검증**했다.

### 5. 「없다」로 단정했다가 틀렸다

「증원 통로가 닫혀 있다」고 썼는데, 실무 담당자가 **정기직제요구가 매년 있다**고
정정해 주었다. 통로는 열려 있고, 문제는 **요구해도 반영되지 않고 반영되어도 1년
이상 걸린다**는 것이었다.

「없다」로 쓰면 아는 사람의 반박 한 번에 무너진다.
**「있다. 다만 실효와 시차가 문제다」**가 사실에 맞고 더 강하다.

## 얻은 것

1. **조사원은 병렬로, 판단은 사람이.** 수집은 나눌수록 빨라지지만, 무엇을 싣고
   가릴지는 나눌 수 없다.
2. **근거에 등급을 매긴다.** 특히 「내부 검토(안)」과 「확정 사실」을 섞지 않는다.
3. **조사원의 판정은 검증한다.** 규정 대조·현황 판정처럼 **없음을 근거로 한 추론**은
   특히 틀리기 쉽다.
4. **인용할 핵심 수치는 원자료를 직접 연다.** 요약을 옮기면 요약의 오류를 물려받는다.
5. **「없다」고 단정하지 않는다.** 확인 범위를 밝히고, 아는 사람에게 묻는다.

## 공개 범위

본 과제의 실제 산출물(보고서·붙임·내부 현황 조사 결과)은 **기관 내부 인력 자료**를
담고 있어 공개하지 않는다. 여기에는 **에이전트 설계·명령·도구**와, **공개 자료만으로
만든 정책조사 결과**를 올린다.

- `agents/`, `command/` — 다른 주제·기관에도 그대로 쓸 수 있도록 내부 자료 경로와
  문서명을 일반화했다.
- `output/` — 교육부·지자체·전문기관의 **공개된 기본계획·지침·보도자료**를 조사한 결과.
- 내부 현황 조사 결과, 보고서 본문, 조직 조정 검토 자료는 **포함하지 않았다.**
