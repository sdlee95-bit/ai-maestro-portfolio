# AI 마에스트로 교육과정 — 과제 포트폴리오

부산대학교 AI 마에스트로 교육과정 수행 과제와 산출물을 정리한 저장소입니다.
각 과제는 **재사용 가능한 자동화 도구(Claude Code 스킬)** 형태로 만들고,
실제 업무 자료에 적용한 결과물을 함께 담았습니다.

| # | 과제 | 내용 | 산출물 |
|---|---|---|---|

## 개인정보 안내

02번 과제처럼 실제 인사자료를 다룬 과제는 **가상 데이터로 만든 데모만** 공개합니다.
실제 적용본과 원본 자료는 저장소에 올리지 않습니다. 데모는 실제와 열 구조와 값의 형태만
같고 내용은 전부 난수이며, 산출물의 모든 시트에 그 사실을 표시했습니다.

## 과제별 폴더 구조

```
NN-과제이름/
├── README.md      과제 개요 · 접근 방법 · 결과
├── skill/         재사용 가능한 자동화 도구 (SKILL.md + 코드 + 자산)
├── preview/       결과물 미리보기 이미지
└── output/        최종 산출물
```

과제에 따라 `skill/` 이 없을 수 있습니다. 도구가 대학 내부 업무 자료·규칙에 밀착해
있는 경우에는 산출물과 설계 설명만 공개하고 코드는 포함하지 않았습니다.

## 저작권 안내

- `skill/scripts/*.py`, `README.md`, `references/*.md` 등 **직접 작성한 코드·문서**는
  자유롭게 참고·수정·재사용하셔도 됩니다.
- `skill/assets/` 의 부산대학교 엠블럼·캠퍼스 사진·서식 파생 파일과, 파일에 임베드된
  서체(페이퍼로지, 공체)는 **각 권리자에게 저작권이 있습니다.** 부산대학교 업무 문서
  작성 목적 외의 사용은 각 권리자의 이용 조건을 확인하시기 바랍니다.
- 이런 사정 때문에 저장소 전체에 단일 오픈소스 라이선스를 적용하지 않았습니다.
