# 디자인 토큰 — 원본 「2026 업무보고 서식」에서 추출

모든 값은 원본 pptx의 XML에서 직접 읽어낸 것이다. 임의로 바꾸면 원본과의
일관성이 깨지므로, 새 요소를 만들 때도 이 표 안에서만 고른다.

## 5. 헤더 도형 (본문 슬라이드)

원본 slide4의 `자유형: 도형 10 / 13` 을 그대로 재현.

- **탭 도형** : custGeom, path `w=581025 h=644664`
  (위 두 모서리 직각, 아래 두 모서리 R=144466)
  - 채움 탭 : `off=(323685, 0)`, `ext=(541881, 707886)`, solid `1C4FA1`
  - 윤곽 탭 : `off=(407364, 0)` (오른쪽 +83679 EMU 어긋나게), 선만 `1C4FA1` 0.75pt
- **번호** : 채움 탭 중앙, 15pt 페이퍼로지 9 Black, 흰색
- **제목** : `x=1.24in`, 22pt 페이퍼로지 9 Black, `1C4FA1`, 자간 −0.6
  (폭 9.16in 초과 시 0.5pt씩 자동 축소, 하한 14pt)
- **로고 락업** : `x=10.62` 세로 구분선 → `10.76` 텍스트 →
  `12.44` 엠블럼 0.68in (우측 끝 13.12in — 원본 로고 우측 끝과 동일)

## 6. □ 섹션 헤딩 마커

원본 `직사각형 16 / 17` 재현. 정사각형 2개를 어긋나게 겹친다.

- 뒤(윤곽) : `(x + s×0.23, y + s×0.23)`, 선만 `1C4FA1` 0.75pt
- 앞(채움) : `(x, y)`, solid `1C4FA1`
- 한 변 `s = 섹션글자크기 / 190` (28pt → 0.147in)

## 7. 배경

| 슬라이드 | 배경 |
|---|---|
| 표지 | solid `1C4FA1` + 우측 사진(6.03in) + 가로 그라데이션 베일 (100% → 80%@55% → 40%) |
| 목차 | solid `1C4FA1` + 상단 1.42in 흰 띠 위에 흑백 캠퍼스 사진 alpha 15%, `srcRect t=33915 b=50083` |

| 본문 | solid 흰색 |

## 8. ※ 노트 밴드

- 배경 : 사각형 `DCEAF7`, 좌우 패딩 0.09in
- 「※ 」 는 남색 볼드, 본문은 12pt 페이퍼로지 4 Regular `INK`, 행간 1.30
- 원본 slide7의 `TextBox 22` 와 동일

## 9. 표

- 머리행 : `1C4FA1` 배경 + 흰색 11.5pt 페이퍼로지 6 SemiBold, 가운데 정렬
- 본문행 : 흰색 / `F4F7FC` 교대, 11.5pt 페이퍼로지 4 Regular `INK`
- 괘선 : 4면 `BFD0E8` 0.75pt (`w=9525`)
- `tblPr` 의 `firstRow` / `bandRow` 를 0으로 꺼서 PowerPoint 기본 줄무늬 제거
- `tcPr` 자식 순서 규칙상 `lnL·lnR·lnT·lnB` 를 **맨 앞에** insert 해야 한다

## 10. 줄높이 추정

```
높이(in) = 줄수 × 글자크기(pt) × 행간비율 × LINE_FACTOR / 72
LINE_FACTOR = 1.07   # PowerPoint 실측 보정
줄수 = ceil(전각환산폭 / (가용폭(pt) / 글자크기(pt)))
전각환산폭: 한글·한자 1.0em, 그 외 0.5em
```
