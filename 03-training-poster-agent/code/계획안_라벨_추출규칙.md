# 계획(안) 라벨 · 추출 규칙

계획(안)은 담당자와 시기에 따라 **같은 항목을 다른 라벨로 쓴다.** 라벨을 하나만 보면
값이 통째로 빈 채 포스터가 나간다. 새 달을 돌릴 때 추출 결과를 먼저 눈으로 볼 것.

## 1. 라벨 혼용 (2025-02 ~ 2026-09, 19건 확인)

| 항목 | 쓰이는 라벨 | 비고 |
|---|---|---|
| 교육 주제 | `교육내용` · `교육주제` · **`교육과정`** | `교육과정` 은 2025-03·06·07·09·11, 2026-03 |
| 일시 | `교육일시` · **`교육기간`** | 이러닝 달은 대개 `교육기간` |
| 대상 | `교육대상` | |
| 운영 | `운영방법` | 유형 판정의 주 근거 |

`field(t, *names)` 에 이름을 **여러 개 넘겨** 먼저 걸리는 것을 쓴다. 새 라벨이 나오면
여기에 적고 `plan_extract.py` 의 해당 줄에 추가한다.

패턴은 `[○ㅇ●]?\s*라벨\s*[:：]\s*(값)` 이다. 글머리 기호가 달마다 다르다.

## 2. 라벨이 아닌 값들

| 값 | 찾는 방법 |
|---|---|
| 장소 | `대면 집합교육(…)` 괄호 안 |
| 이러닝 종료일 | 일시 원문의 `~ 5. 31.(일)`. 요일이 없으면 계산해 넣는다 |
| 수강처 | `(홈페이지) …` |
| 진도율 | `진도율 100%` |
| 상시학습 | `상시학습시간 인정 : …` — **원문을 그대로 쓴다** |
| 이수기준 | `비대면 교육 이수 기준 :` 없으면 `전체 교육시간 N% 이상 이수` |
| 캠퍼스 특례 | `양산·밀양 …(인정\|참여…)` |
| 참석 예외 | `부서별 필수요원 …` — 다음 글머리(`- ○ ※`)까지 |
| 근거 법령 | `교육시행근거 : …` |

## 3. 이러닝 강좌 표 (`parse_courses`)

이러닝 계획안에는 강좌 표가 있다. PDF 에서 표가 한 줄씩 풀려 나온다.

```
구분 / 적극행정교육 / 갈등관리교육
강좌명 / [5월 직장교육] / 국민의 생활을 / 바꾸는 적극행정 / [5월 직장교육] / 조직갈등 SOS! / 이럴 때 나라면?!
인정시간 / 50분 / 1시간 10분
이수기준 / 진도율 100%
이수사이트 / 부산대학교 나라배움터
```

- `구분` 과 `인정시간` 은 한 줄에 하나씩이라 그대로 읽는다.
- **강좌명만 여러 줄로 쪼개진다.** 「`[N월 직장교육]`」 표시를 기준으로 나눈다.
- 9건 모두 2강좌 · 진도율 100% · 나라배움터였다. 3강좌는 본 적이 없다.

수강 절차(`parse_flow`)도 도표라 화살표가 한 줄씩 나온다 —
`접속 / → / 수강신청 및 수강 / → / 교육이수 / → / 상시학습인정`. 9건 모두 같다.

### 표와 교육내용이 어긋나는 달이 있다

**2026년 1월 계획안** — 교육내용은 「폭력예방교육, 반부패·청렴교육」인데
표의 구분은 「통일교육 / 갈등관리교육」이다. 인정시간(4시간 / 5시간 22분)은
폭력예방·반부패 값이라, 지난 계획안을 복사해 쓰면서 **구분 행만 안 고친** 것으로
보인다.

`check_courses()` 가 이걸 잡아 알린다. **임의로 고치지 않는다.** 어긋나는 정보가
실린 포스터가 전 구성원에게 나가지 않도록 기본값에서는 파일을 만들지 않고,
확인용으로 뽑아야 하면 `--ignore-warning` 을 준다.

> 교육내용을 쉼표로만 자를 것. `·` 로 자르면 「반부패**·**청렴교육」이 두 건으로
> 세어져 멀쩡한 달이 어긋난 것으로 잡힌다.

## 4. 강사 — 이름 길이로 판별한다

계획안의 강사는 표 안에 있고 열 순서가 `강의시간 / 교육내용 / 강사` 다. "강사" 뒤
글자를 읽으면 **교육내용이 먼저 걸린다**(실제로 「력예방교육」이 강사로 나왔다).

직위 낱말(강사·교수·대표…)이 괄호 안에 있는지로 걸렀더니 「(청렴연수원)」처럼
**기관명만 있는 경우**를 놓쳤다. 직위 목록을 늘리는 건 끝이 없다.

지금 방식 — `이름 \n (소속)` 꼴을 모두 모으고 **이름이 4음절 이하**인 것만 남긴다.
한국 사람 이름은 2~4음절이고 이 문서들은 「이 안 나」처럼 띄어 쓴다.
「폭력예방교육」은 5음절이라 자연히 걸러진다. 직위 낱말이 있는 후보를 우선하고,
하나도 없으면 길이 조건만 통과한 후보를 쓴다.

## 5. 유형 판정 — `detect_mode()`

`운영방법` + 본문 앞 2500자를 본다.

| 조건 | 유형 |
|---|---|
| 이러닝/나라배움터 있고 집합교육 없음 | 이러닝 |
| 집합교육 + ZOOM·비대면 | 혼합 |
| 집합교육만 | 집합 |
| 그 밖 | 미상 |

**미상이 나오면 포스터를 내지 말고 계획안을 직접 확인한다.**

## 6. 파일 형식

- **PDF** — PyMuPDF(`fitz`) 로 페이지별 `get_text()`.
- **HWPX** — zipfile + ElementTree. `<hp:t>` 의 `.text` 만 이으면 `<hp:fwSpace/>` 뒤의
  **`tail` 이 누락돼** 날짜·수치가 잘린다(`’26. 3. 31.` → `’26.`).
  자식 요소의 `tail` 까지 이어 붙일 것.
- 전각 공백(` `)을 반각으로 바꾸고 연속 공백을 하나로 줄인 뒤 정규식을 건다.

## 7. 값이 없으면 비워 둔다

원자료에 없는 값을 지어내지 않는다. 비워 두고 **무엇이 비었는지 콘솔에 알린다.**
그럴듯한 숫자·문구를 채우는 것이 가장 위험하다.
