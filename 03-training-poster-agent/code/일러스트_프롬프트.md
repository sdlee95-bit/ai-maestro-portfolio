# 직장교육 안내 포스터 — 일러스트 생성 프롬프트

**역할 분담**
- **생성 AI** : 글자 없는 일러스트만
- **에이전트(코드)** : 모든 글자 — 계획안에서 뽑은 값 그대로 조판

이렇게 나누는 이유는 생성 AI가 한글을 틀리기 때문이다. 참고로 주신
「대학회계직원 근무 가이드」에서도 *규정이 **장한** 사유 없이*(→정한),
*특별한 **공작이** 있는*(→공적이) 두 곳이 틀렸다. 전 구성원에게 뿌리는
문서에서는 허용될 수 없는 오류이고, 매달 반복하는 업무라면 매번 사람이
눈으로 잡아야 한다. 그래서 **글자는 생성 AI에 맡기지 않는다.**

## 0. 모든 프롬프트에 공통으로 넣을 것

생성 도구가 무엇이든 아래 네 가지는 반드시 포함한다.

```
글자·문자·숫자·로고·워터마크를 일절 넣지 마세요. (no text, no letters,
no numbers, no words, no logos, no watermark, no signage)
```

| 항목 | 지정값 | 이유 |
|---|---|---|
| 비율 | 가로 16:9 (메일 발송 기준) | 조판기 기본값과 같음 |
| 배경 | 단색 또는 아주 옅은 단색 | 글자를 얹을 자리 확보 |
| 여백 | **왼쪽 절반은 비워 둘 것** | 제목·일시가 들어가는 자리 |
| 팔레트 | 남색 #1C4FA1 · 하늘 #2DA7E0 · 크림 #F5F1E8 | 기존 포스터·PPT와 같은 계열 |

> **NotebookLM 주의** — 출력 우측 하단에 NotebookLM 워터마크가 찍힌다.
> 공식 배포물에는 부적절하므로, 워터마크가 없는 도구(ChatGPT·Gemini·
> Copilot 등)를 쓰거나 워터마크 영역이 잘려도 되도록 여유를 두고 생성한다.

## 1. 9월 교육 — 폭력예방교육(성매매·가정폭력)

### 먼저, 이 주제에서 절대 피해야 할 것

주제가 무겁다. 이미지가 잘못되면 사안을 가볍게 만들거나 특정 집단을 낙인찍는다.

| 금지 | 이유 |
|---|---|
| 겁에 질린 사람·웅크린 사람·우는 얼굴 | 피해자를 전시하는 구도가 된다 |
| 주먹·손찌검·그림자 위협·붉은 경고색 | 폭력을 재현한다. 예방교육의 목적과 반대 |
| 남성=가해자 / 여성=피해자 구도 | 성별 고정관념을 강화한다 |
| 수갑·철창·법봉 | 처벌 메시지. 이건 **예방·인식** 교육이다 |
| 귀여운 동물·꽃·스쿨버스 같은 장식 | 8월 포스터의 실패. 사안의 무게와 안 맞는다 |

**지향점** — 「함께 지키는 안전한 일터」. 존중·연대·배움. 무섭지 않되 진지하게.

### 안 1 — 동등한 동료들 (권장)

> 부드러운 클레이(점토) 3D 렌더링 스타일의 일러스트를 만들어 주세요.
> 다양한 연령과 성별의 직장 동료 서너 명이 같은 눈높이로 나란히 서서
> 서로를 향해 편안하게 대화하는 모습입니다. 표정은 차분하고 온화하며,
> 특정 인물이 더 크거나 높이 있지 않고 모두 동등하게 배치됩니다.
> 뒤로는 부드러운 반원형 보호막이 은은하게 감싸고 있습니다.
> 배경은 아주 옅은 크림색 단색이고, **화면 왼쪽 절반은 비워 두세요.**
> 인물과 요소는 오른쪽에 모읍니다.
> 색은 남색·하늘색·크림색 위주의 차분한 파스텔로 해 주세요.
> 조명은 부드럽고 그림자는 옅게, 질감은 점토처럼 매끈하게.
> **글자·문자·숫자·로고·워터마크를 일절 넣지 마세요.**
> 비율은 가로 16:9.

```
Soft clay / claymation 3D render illustration. Three or four office
colleagues of varied age and gender standing side by side at the SAME
eye level, turned slightly toward each other in calm, respectful
conversation. Gentle, composed expressions. No one is larger or placed
higher than the others. Behind them a soft translucent dome-shaped
shield arcs protectively, very subtle. Plain very-light-cream
background. LEAVE THE LEFT HALF OF THE FRAME EMPTY — group the figures
on the right side. Palette: navy blue, sky blue, cream pastels. Soft
diffused lighting, gentle shadows, smooth matte clay texture.
NO TEXT, NO LETTERS, NO NUMBERS, NO LOGOS, NO WATERMARK, NO SIGNAGE.
16:9 landscape.
```

> 보호막(돔 형태)이 있고, 서너 개의 손이 아래에서 그 보호막을 함께
> 떠받치고 있습니다. 손은 크기와 피부톤이 조금씩 달라 여러 사람이

## 2. 받은 뒤 할 일

1. 생성한 PNG 를 `02.작업/illust/` 에 넣는다. 파일명은 자유.
2. 조판 실행 — 글자는 계획안에서 다시 뽑아 얹으므로 오타가 날 수 없다.

```bash
python 02.작업/make_poster.py \
  --plan "01.원본데이터/260902 2026년 9월 직장교육 계획(안).pdf" \
  --outdir "03.산출물" \
  --illust "02.작업/illust/받은파일.png" \
  --styles D
```

3. 여러 장 받았으면 `--illust` 만 바꿔 여러 벌 뽑아 고른다.

## 3. 다음 달부터 — 주제만 바꿔 쓰는 표

공통 규칙(0항)과 금지 목록은 그대로 두고, **주제 묘사 한 문단만** 갈아끼운다.

| 교육 주제 | 일러스트 방향 | 피할 것 |
|---|---|---|
| 폭력예방(성희롱·성폭력·성매매·가정폭력) | 동등한 동료, 보호막, 존중 | 피해자 묘사, 폭력 재현, 성별 고정 |
| 청렴·부패방지 | 저울, 투명한 유리, 곧은 길 | 수갑·돈다발·검은 손 (범죄자 프레임) |
| 안보·통일교육 | 지도, 악수, 이어지는 길 | 군사 무기, 특정 국가 비하 |
| 적극행정·갈등관리 | 함께 미는 수레, 맞물리는 톱니 | 싸우는 장면, 삿대질 |
| AI·평생학습 | 책과 회로가 어우러진 형태, 성장하는 새싹 | 인간을 대체하는 로봇 구도 |
| 안전보건·재난대응 | 헬멧, 소화기, 대피 경로 | 사고 현장 재현, 부상자 |

**이러닝 달**(강사·장소가 없는 달)은 인물 대신 **기기 위주**로 간다 —
노트북·태블릿에서 학습이 진행되는 모습. 단 화면에는 글자를 넣지 않는다.

## 4. 왜 배경을 사진 대신 일러스트로 가는가

앞서 만든 B안(사진 배경)은 접었다. 이유를 남겨 둔다.

- 성매매·가정폭력 예방에 어울리는 **사진**은 사실상 없다. 인물 사진은
  피해자를 연상시키고, 풍경 사진은 주제와 무관하다. 실제로 해변 일몰을
  넣었더니 휴양 느낌이 나서 걷어냈고, 나뭇잎으로 바꿔도 연결이 약했다.
- 일러스트는 **추상적 상징**(보호막·동등한 배치)을 쓸 수 있어 이 주제에 맞다.
- 사진 방식은 주제가 중립적인 달(AI 평생학습, 청렴교육 등)에 쓰면 된다.
  `fetch_bg.py` 와 B안 코드는 그대로 남겨 두었다.
